AgentPay API Reference

Complete REST API documentation for AgentPay - Financial rails for autonomous AI agents. Virtual cards, budgets, and spend management.

Introduction

The AgentPay API allows you to programmatically manage virtual cards, spending policies, and transactions for AI agents. Our REST API uses JSON for all requests and responses.

Base URL

https://api.agentpay.co/v1

Authentication

API Key Authentication

All API requests must include your API key in the Authorization header using the Bearer scheme:

Authorization: Bearer sk_live_your_api_key_here

You can obtain your API key from the AgentPay dashboard under Settings → API Keys.

Cards API

POST /v1/cards

Creates a new virtual card for an AI agent with specified spending limits and policies.

Request Body

{
  "agent_id": "agent_claude_001",
  "display_name": "Claude Research Assistant",
  "spending_limit": 5000,
  "currency": "USD",

    "research_tools",
    "cloud_computing"

  "auto_approve_limit": 100,

    "department": "AI_team"

POST /v1/transactions/{transaction_id}/approve

Manually approves a pending transaction that requires human review.

Request Body

{
  "reason": "Approved for legitimate research purposes",
  "approved_by": "blake@agentpay.co"
}

Response

{
  "id": "txn_m2n3o4p5q6r7",
  "status": "approved",

  "approved_by": "blake@agentpay.co",
  "approval_reason": "Approved for legitimate research purposes",
  "message": "Transaction approved successfully"
}

Webhooks

AgentPay sends webhook events to notify your application about important events in real-time. Configure webhook endpoints in your dashboard.

transaction.created

Fired when a new transaction is initiated by an agent.

{
  "event": "transaction.created",
  "data": {
    "id": "txn_7h8i9j0k1l2m",
    "card_id": "card_1a2b3c4d5e6f",
    "agent_id": "agent_claude_001",
    "amount": 29.99,
    "currency": "USD",
    "merchant": "OpenAI API",
    "status": "pending"
  },
  "created_at": "2026-02-02T14:30:00Z"
}

transaction.approved

Fired when a transaction is approved (either automatically or manually).

{
  "event": "transaction.approved",
  "data": {
    "id": "txn_7h8i9j0k1l2m",
    "card_id": "card_1a2b3c4d5e6f",
    "agent_id": "agent_claude_001",
    "amount": 29.99,
    "status": "approved",
    "auto_approved": true,
    "approved_at": "2026-02-02T14:30:01Z"
  },
  "created_at": "2026-02-02T14:30:01Z"
}

transaction.declined

Fired when a transaction is declined due to policy violations or manual rejection.

{
  "event": "transaction.declined",
  "data": {
    "id": "txn_m2n3o4p5q6r7",
    "card_id": "card_1a2b3c4d5e6f",
    "agent_id": "agent_claude_001",
    "amount": 299.00,
    "status": "declined",
    "decline_reason": "Exceeds daily spending limit",
    "declined_at": "2026-02-02T16:50:00Z"
  },
  "created_at": "2026-02-02T16:50:00Z"
}

card.created

Fired when a new virtual card is created for an agent.

{
  "event": "card.created",
  "data": {
    "id": "card_1a2b3c4d5e6f",
    "agent_id": "agent_claude_001",
    "display_name": "Claude Research Assistant",
    "spending_limit": 5000,
    "status": "active"
  },
  "created_at": "2026-02-02T16:19:14Z"
}

policy.violated

Fired when a transaction violates a spending policy, requiring manual review.

{
  "event": "policy.violated",
  "data": {
    "transaction_id": "txn_m2n3o4p5q6r7",
    "policy_id": "policy_x1y2z3a4b5c6",
    "policy_name": "AI Research Policy",
    "violated_rule": "daily_limit",
    "violation_details": {
      "limit": 500,
      "attempted_amount": 299,
      "current_daily_spend": 450
    },
    "requires_approval": true
  },
  "created_at": "2026-02-02T16:15:00Z"
}
